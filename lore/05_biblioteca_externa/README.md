# 05 · Biblioteca externa

Libros, crónicas antiguas y documentación histórica, técnica, filosófica o académica. Normalmente **anteriores al 5500 o de origen externo** a la colonia.

> Distinción: esta carpeta es **lore dentro del mundo**. La carpeta `Library/` de la raíz del repositorio es personal del jugador y no tiene relación con ella.

- Nombre de archivo: `AAAA-MM-DD_libro_autor_titulo-corto.md` o `..._cronica_...` (ver [`../_convenciones.md`](../_convenciones.md)). Una obra larga puede ser una carpeta con `indice.md`.
- Plantilla: [`../_plantillas/documento_inworld.md`](../_plantillas/documento_inworld.md).
- Indica siempre quién lo escribió, cuándo y desde qué punto de vista: una crónica oficial puede estar sesgada.
