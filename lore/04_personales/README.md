# 04 · Personales

Diarios privados, notas y cartas. Voz subjetiva, filtrada por las emociones y los límites de conocimiento de cada autor. Las cartas llevan fecha explícita y pueden venir de personas ajenas a la colonia.

- Nombre de archivo: `AAAA-MM-DD_tipo_autor_titulo-corto.md`, con `tipo` = `diario`, `nota` o `carta` (ver [`../_convenciones.md`](../_convenciones.md)).
- Plantilla: [`../_plantillas/documento_inworld.md`](../_plantillas/documento_inworld.md).
- Cada autor debe sonar distinto; consulta su ficha en [`../01_personajes.md`](../01_personajes.md).
