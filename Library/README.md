# Library

Carpeta **personal del jugador**.

Aquí van tus materiales de trabajo: notas sueltas, borradores, capturas, ideas, referencias… lo que quieras guardar sin que forme parte del lore oficial.

- Claude puede leerla como contexto **solo cuando se lo pidas**.
- Nada de lo que hay aquí es canon hasta que lo traslades al lore (`/lore/`) o lo confirmes expresamente.
